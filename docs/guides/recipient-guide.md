# You've been invited to a shared conversation

You were sent two things — keep them separate:

- **A link**, e.g. `https://xxxxx.ngrok-free.app/mcp`
- **An invitation code**, e.g. `pinv_v1_...` (one-time use)

## Setup (ChatGPT, one time)

1. **Settings → Security and login → Developer mode** → turn on.
   *(Needs a paid plan — Plus/Pro/Team/Business/Enterprise. Desktop web, not mobile.)*
2. **Settings → Connectors → Create**:
   - Name: `Prism`
   - MCP server URL: paste the **link** you were sent
   - Auth: leave as automatic — save.
3. A browser tab opens asking for your **name** and the **invitation code**. Enter both, submit.
4. You'll see "waiting for approval" — the sender has to confirm it's you. Once they do, you're connected.

## Ask it questions

New chat → **+ / tools** → turn on **Prism** → ask:

- *"Use Prism to summarize what was shared with me."*
- *"Ask Prism what was decided about [topic]."*

You'll only see what the sender chose to share — nothing else from their account.

## If something's stuck

- No "Connectors" in Settings → wrong plan, or use desktop web
- "Invalid/expired code" → ask for a fresh one
- Stuck on "waiting for approval" → ask the sender to approve on their end
